# 🔎 OSINT Username Finder

Pequeña herramienta desarrollada en Python para buscar nombres de usuario en diferentes plataformas.

## Plataformas compatibles

- GitHub
- Reddit
- Twitch
- Instagram
- TikTok

## Tecnologías

- Python
- CustomTkinter
- Requests
- BeautifulSoup4

## Ejecución

Instala las dependencias:

pip install customtkinter requests beautifulsoup4

Ejecuta el programa:

python osint.py

## Aviso

Proyecto educativo para aprender sobre OSINT.
Utiliza únicamente información pública y respeta la privacidad de los demás.
